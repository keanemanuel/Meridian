New feature: in the Rooms tab, allow dragging a division badge
(e.g. the highlighted "FNB" button shown at the top of a room
card) from one room card and dropping it onto a different room
card, to relocate that entire panel to the new room.

Behavior:
1. Dragging a division badge (representing one panel, e.g.
   "FNB-BAL-1" currently in Room 2016) and dropping it onto
   another room card (e.g. Room 3013) moves that panel to the new
   room — only the room assignment changes; all its existing
   interviews/schedule stay attached to that panel, unchanged.
2. Respect existing hard constraints: the drop should be rejected
   (with a clear message) if it would violate room-exclusivity
   (target room already has a panel of the same division). The
   4-panel room ceiling should NOT block this for manual moves —
   consistent with Session G4's manual-cap-removal rule, since
   this is also a manual action.
3. After a successful move, both the source room card (panel
   removed) and target room card (panel added) update immediately
   without a page reload, and all dependent views (Room View,
   Applicants tab) reflect the change.
4. This is scoped to the Rooms page only — Room View / Applicants
   tab are not required to have this drag interaction.

Run pytest. If tests pass, commit and push.
